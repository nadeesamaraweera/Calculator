# 🔢 Simple HTML Calculator  

This repository features a simple calculator built using **HTML, CSS, and JavaScript**. The application provides basic arithmetic operations with a **responsive design** for optimal usability across different devices.  

## ✨ Features  
✅ Basic arithmetic operations (+, -, ×, ÷)  
✅ Clear and backspace functionality  
✅ Responsive design for various screen sizes  

## 🛠 Technologies Used  
- **HTML** for structure  
- **CSS** for styling and responsiveness  
- **JavaScript** for interactive functionality  

## 🚀 Usage  
1. Clone the repository:  
   ```bash
   git clone https://github.com/nadeesamaraweera/Calculator.git
   ```
2. Open the `index.html` file in a browser.  
3. Start performing calculations!
